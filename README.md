# Brizzom Shop

**Brizzom Shop** es un proyecto personal de desarrollo web que consiste en crear una tienda online de moda con una estética minimalista, elegante y editorial.

El proyecto nace con el objetivo de construir una aplicación completa de comercio electrónico, trabajando tanto el frontend como el backend y la gestión de datos, mientras profundizo en tecnologías de desarrollo web.

> 🚧 **Estado del proyecto:** En desarrollo.

## 🎨 Diseño

La identidad visual de Brizzom Shop se basa en una estética minimalista y editorial, inspirada en las tiendas de moda contemporáneas.

Principales criterios de diseño:

- Paleta de colores neutros y tonos cálidos.
- Jerarquía tipográfica cuidada.
- Interfaz limpia y funcional.
- Diseño responsive.
- Componentes reutilizables.
- Transiciones y animaciones sutiles.

## 🚀 Instalación y ejecución

### Requisitos previos

- Node.js y npm.
- Angular CLI compatible con la versión del proyecto.

### Pasos

1. Clona el repositorio:

   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. Accede al frontend:

   ```bash
   cd brizzom-shop/frontend
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   ng serve
   ```

5. Abre [http://localhost:4200](http://localhost:4200) en tu navegador.
